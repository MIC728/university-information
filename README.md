# 一些大学的生活质量调查：问卷数据

原项目：https://github.com/CollegesChat/university-information

本项目是基于原项目数据的二次整理。

## 友情提示

- 数据都有些滞后（最早来自2023 年 1 月 1 日），不代表学校的最新情况
- 数据是否准确真实请自行甄别
- 数据收集肯定做不到随机取样，从同一个渠道了解到并填写问卷的学生，对某些问题的看法可能也会更一致

## 修改内容

- 校正了错误的拼音
- 去掉了外国大学
- 基于正确拼音顺序生成新索引（不含外国大学）
- 制作了数据清洗后的PDF版本

## 关于PDF版本

制作PDF版本的初衷是方便传播和浏览。本来我打算把所有数据合并成一个PDF文件再加目录，但是数据量还是太大了，即使经过数据清洗，最后的pdf文件也会有上千页，几乎没有软件能够流畅打开。所以最终采取了一个折中方案，把数据按大学拼音首字母拆分成多个PDF文件。

数据清洗很简单粗暴，去掉了所有外国大学和所有只有一个人填写问卷的大学。
